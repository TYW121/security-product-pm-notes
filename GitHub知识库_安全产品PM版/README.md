# 安全 / 数据产品 PM 知识库（法规语料 × 产品拆解 × 公开证明）

> 主人：TYW121 ｜ 配套《一年行动计划（安全 / 数据安全产品经理方向版）》
> 一句话定位：这个仓库同时是三样东西——**产品合规语料库**（做安全/数据产品时随查随用）、**产品功能拆解训练记录**（每天 30min 的 PM 基本功）、**带时间戳的公开证明**（招聘方一搜即见"既懂合规又懂产品"）。

## 这个库怎么证明你的能力？

合规圈 / 产品圈都没有"我读过法""我会做产品"的证书。本库用 **四重证据链** 自证：

1. **时间戳** —— GitHub 的 commit 历史不可伪造。每一次"读了一条法、拆了一个功能"都留下日期，坚持本身就是最硬的记录。
2. **理解痕迹** —— 每条法规 / 每个功能一篇结构化笔记，含"原文摘录 + 我的批注 + 产品场景映射"，能看出是真读懂，不是抄目录。
3. **应用产出** —— 笔记挂接衍生物：竞品分析、合规差距报告、出境决策树、毕设规则库、科普文链接，证明"读/拆"转化成了"能做"。
4. **第三方背书** —— `related_outputs` 里记录 OneTrust 免费微证书、软考中项、NISP L1、CISP-DSG、雅思等，外部验证。

## 目录结构

```
security-product-pm-notes/
├─ README.md                      # 本说明（仓库门面）
├─ _模板_法规笔记.md              # 法规笔记填空模板（复制改名即用）
├─ _模板_产品功能拆解.md          # 每日产品拆解填空模板（复制改名即用）
├─ 法规笔记/                      # 每条法规一篇
│  └─ PIPL-个人信息保护法.md      # 示例：已填好，照着写
└─ 产品拆解/                      # 每天一篇，命名如 2026-11-04_小红书-收藏夹.md
```

## 使用流程（与微习惯对齐）

1. **法规线**：晨间 15min 读条款 → 当晚 5min 按模板补进对应笔记。`status` 从 `规划中 → 通读中 → 精读中 → 已完成` 推进。
2. **产品线**：每天 30min 拆一个功能 → 按拆解模板新建一篇。Q1 拆通用 App 练手感，Q2 起主拆安全/数据产品（IAM、DLP、数据分类分级、零信任）。
3. **每周小产出**：周末汇总成对照表 / 框架图，挂进对应笔记第 4 节。
4. **公开即证明**：仓库设 **Public**，简历 / 作品集直接附链接。

## 产品功能拆解计划

| 阶段 | 拆什么 | 目的 |

| Q1 | 通用 App（微信 / 小红书 / 美团…）每天 1 个功能 | 练"用户视角 + 结构化表达"基本功 |

| Q4 | 毕设相关产品（数据分类分级 / 合规检查类） | 毕设与求职互相喂养 |
